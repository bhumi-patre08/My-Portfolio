# Responsive Personal Portfolio Website

A professional, fully responsive, and highly interactive personal portfolio website built entirely with native web technologies. This project showcases frontend architecture fundamentals, asset optimization, and live third-party API integration without relying on heavy external frameworks.

## Implemented Features

### 1. Structure & Modern SEO Layout
- **Semantic HTML5:** Built using structure-specific tags (`<article>`, `<section>`, `<nav>`) to maximize SEO indexability.
- **Meta Optimization:** Configured optimized meta descriptions, viewport scaling properties, and custom favicon headers.

### 2. Advanced CSS Styles & Responsiveness
- **Mobile-First Design:** Implemented fluid responsive layouts using native CSS Media Queries and Flexbox/Grid systems.
- **Theming Toggle:** Built a dynamic Light/Dark mode UI theme controller powered by JavaScript and persistent `localStorage` states.

### 3. Core JavaScript Interactivity
- **Smooth Navigation:** Handled document anchor scrolling effects natively via browser window APIs.
- **Dynamic Project Filters:** Created client-side interactive tag filters to sort project asset cards on the fly.
- **GitHub API Integration (Bonus):** Integrated real-time repository data fetching from the GitHub API to showcase live statistics on project components.

### 4. Performance & Asset Optimization
- **Image Compacting:** Converted all visual assets to modern `.webp` file formatting to heavily compress page payload weight and speed up rendering.
- **Resume Portal:** Attached a functional asset download bridge for quick resume retrieval.
